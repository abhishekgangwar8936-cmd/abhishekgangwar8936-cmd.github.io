## 🌟 Highlights & Key Features

- **🎨 Interactive WebGL GLSL Shader Background:** Custom-written fluid dynamics canvas shaders running smoothly at consistent 60 FPS with mouse proximity reactivity.
- **⚡ Zero-Flicker Clean URLs:** Built-in client routing with `window.history.replaceState` and a smart 404 auto-router that seamlessly strips `.html` extensions and handles subpaths.
- **🌓 Dynamic Dark / Light Theming:** Persistent theme toggle with `localStorage` memory and smooth color transitions.
- **📜 Lenis Smooth Scrolling:** Inertial physics scrolling for desktop navigation with zero Cumulative Layout Shift (CLS).
- **📱 100% Mobile & Touch Optimized:** Fluid responsive layouts crafted with utility-first Tailwind CSS and lightweight Alpine.js reactive components.
- **🔍 SEO & Schema.org Ready:** Rich JSON-LD structured data, Open Graph previews, and sitemap indexing.

## 🛠️ Local Development & Quick Start

You can run this project locally without any complex build tools or dependencies:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/abhishekgangwar8936-cmd/abhishekgangwar8936-cmd.github.io.git
   cd abhishekgangwar8936-cmd.github.io
   ```

2. **Serve locally with Python:**
   ```bash
   # Python 3
   python -m http.server 8000
   ```

3. **Open in your browser:**
   ```text
   http://localhost:8000
   ```
